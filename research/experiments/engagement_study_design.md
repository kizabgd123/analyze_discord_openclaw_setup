# User Engagement Study

**Hypothesis:** Proactive behavior increases user engagement

## Variables
- Independent: proactive_behavior (on/off)
- Dependent: response_rate, engagement_score, session_length
- Control: time_of_day, user_experience_level

## Experimental Protocol
1. Recruit 30-50 Discord users from similar communities
2. Randomly assign to control (reactive-only) or treatment (proactive) groups
3. Run for 2 weeks with equivalent bot functionality otherwise
4. Measure engagement metrics daily
5. Conduct post-study survey
