# External Knowledge Integration Study

**Hypothesis:** NotebookLM integration improves factual accuracy and reduces hallucinations

## Variables
- Independent: knowledge_source (internal_only/NLM_augmented)
- Dependent: factual_accuracy, hallucination_rate, user_satisfaction
- Control: question_difficulty, topic_domain

## Experimental Protocol
1. Create benchmark of 100 factual questions across domains
2. Run each question through both system versions
3. Have experts fact-check responses
4. Measure hallucinations via fact-checking
5. User preference study for answer quality
