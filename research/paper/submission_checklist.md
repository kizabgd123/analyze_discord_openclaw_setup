# Submission Checklist

## Pre-submission Verification

### Paper Content
- [x] Abstract is complete and compelling
- [x] Introduction clearly motivates the problem and contributions
- [x] Related work comprehensively covers relevant literature
- [x] System design includes detailed technical description
- [x] Experiments section clearly describes methodology
- [x] Results present all key findings with statistics
- [x] Discussion addresses implications and limitations
- [x] Conclusion summarizes contributions and future work
- [x] All sections flow logically and use consistent terminology

### Figures and Tables
- [x] System architecture figure included (TikZ diagram)
- [x] Comparison table of related work included
- [x] All experiment results tables generated (engagement, safety, knowledge, ablation)
- [x] Figure captions are self-contained
- [x] Table captions explain all columns/rows
- [x] All figures/tables referenced in text

### Bibliography
- [x] All citations in text appear in bibliography
- [x] All bibliography entries are formatted correctly
- [x] No duplicate entries
- [x] References include all key related work
- [x] Bibliography follows target conference style

### Ethical Compliance
- [x] IRB approval documented
- [x] Informed consent described
- [x] Participant compensation described
- [x] Data privacy measures explained
- [x] No identifying information included

### Supplementary Materials
- [x] Cover letter prepared
- [x] Author information confirmed
- [x] Suggested reviewers listed (with conflict checks)
- [x] Data availability statement included
- [x] Code repository prepared for release

### Formatting
- [ ] Paper conforms to target venue page limits
- [ ] Font sizes and margins meet requirements
- [ ] Line spacing and formatting consistent
- [ ] PDF compiles without errors
- [ ] All fonts embedded in PDF

### Final Review
- [ ] Spelling and grammar check completed
- [ ] All author names and affiliations verified
- [ ] Abstract word count within limits
- [ ] Keywords/section headers appropriate for venue
- [ ] Submission metadata complete (title, abstract, etc.)

## Submission Process

### Before Submitting
1. Final read-through by all authors
2. Check for any placeholder text remaining (e.g., "XXX")
3. Verify PDF renders correctly on different systems
4. Ensure supplementary materials ready
5. Prepare submission statement/copyright form

### After Submission
1. Save submission confirmation
2. Note review timeline
3. Prepare backup plan if not accepted
4. Share preprint if venue allows

## Post-submission Contingencies

### If Major Revisions Requested
- [ ] Address all reviewer concerns systematically
- [ ] Update revision plan with specific responses
- [ ] Prepare response letter with point-by-point replies
- [ ] Highlight changes in revised PDF
- [ ] Update related work if needed

### If Minor Revisions Requested
- [ ] Address all reviewer suggestions
- [ ] Prepare brief response letter
- [ ] Verify all typos and formatting issues fixed

### If Rejected
- [ ] Analyze reviewer feedback
- [ ] Identify weaknesses for revision
- [ ] Update paper for next submission
- [ ] Consider venue fit for revision
